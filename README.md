# مقدمة مبسطة إلى لغة بايثون

هذا الملف أُضيف كتجربة للتأكد من إمكانية الاتصال بالمستودع ورفع التغييرات إليه.

## ما هي بايثون؟

بايثون لغة برمجة عالية المستوى، سهلة القراءة، وتُستخدم في تطوير الويب، وتحليل البيانات، والذكاء الاصطناعي، والأتمتة، والتعليم. تعتمد على كتابة تعليمات واضحة وبناء جمل برمجية قريبة من اللغة الطبيعية.

## أول برنامج

```python
print("مرحبًا بالعالم!")
```

الدالة `print` تعرض النص على الشاشة.

## المتغيرات والأنواع

```python
name = "Roya"       # نص
age = 25             # عدد صحيح
price = 19.95        # عدد عشري
is_active = True     # قيمة منطقية
```

لا تحتاج بايثون إلى التصريح بنوع المتغير مسبقًا؛ فهي تحدد النوع تلقائيًا.

## الشروط

```python
score = 85

if score >= 60:
    print("ناجح")
else:
    print("يحتاج إلى مراجعة")
```

المسافات البادئة جزء أساسي من بنية برنامج بايثون.

## الحلقات والقوائم

```python
languages = ["Python", "JavaScript", "Go"]

for language in languages:
    print(language)
```

القائمة `list` تخزن عدة قيم، وتسمح حلقة `for` بالمرور عليها واحدة تلو الأخرى.

## الدوال

```python
def greet(person):
    return f"مرحبًا يا {person}!"

message = greet("Roya")
print(message)
```

الدالة تجمع تعليمات قابلة لإعادة الاستخدام. تستقبل `person` وتعيد رسالة باستخدام `return`.
